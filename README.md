# 📦 Vite Project

A fast and optimized development setup using **Vite**, a next-generation frontend build tool that leverages native ES modules for lightning-fast performance.

## 🚀 Features

* Ultra-fast hot module replacement (HMR)
* Optimized production builds
* Out-of-the-box support for JavaScript, TypeScript, and frameworks like React, Vue, or Svelte
* Easy configuration and extensibility

## ⚙️ Prerequisites

Make sure you have the following installed:

* [Node.js](https://nodejs.org/) (version 14 or above)
* npm (comes with Node.js) or yarn

---

## 🟢 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Kishore-kumar2407/gamefied
cd gamefied
```

### 2. Install dependencies

```bash
npm install
# or
yarn install
```

### 3. Start the development server

```bash
npm run dev
# or
yarn dev
```

The app will be available at `http://localhost:5173/` by default.

---

## ✅ Build for Production

To create an optimized production build, run:

```bash
npm run build
# or
yarn build
```

The output will be available in the `dist/` directory.

You can preview the production build locally using:

```bash
npm run preview
# or
yarn preview
```
